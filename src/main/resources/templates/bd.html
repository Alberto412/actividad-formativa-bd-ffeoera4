Comprobación en phpMyAdmin

Para comprobar los datos directamente en la base de datos:

1. Abrir http://localhost:8080

2. Entrar con usuario root y contraseña rootpass

3. Seleccionar la base partes_trabajo_db

4. Revisar las tablas cliente, tecnico, material, parte_trabajo y parte_material

5. Opcionalmente ejecutar el archivo src/main/resources/sql/vistas.sql para crear vistas SQL de consulta

Consultas simples
SELECT * FROM cliente;
SELECT * FROM tecnico;
SELECT * FROM material;
SELECT * FROM parte_trabajo;
SELECT * FROM parte_material;
SELECT * FROM vista_partes_completas;
SELECT * FROM vista_materiales_usados;
SELECT * FROM vista_coste_partes;
